# Security Policy

## Supported Versions

Security fixes are applied to the latest released version. Please upgrade
before reporting an issue against an older release.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Contact the
maintainer privately through the security contact configured for the GitHub
repository and include:

- A clear description of the impact.
- Steps or a minimal example to reproduce it.
- Affected versions and environment details.

Please allow reasonable time for investigation and a coordinated fix before
public disclosure. Do not include secrets or personal data in the report.
